📖 GPS চালানোর নিয়ম

  1. 📍 আমার অবস্থান বাটনে চাপুন।
  2. Browser যদি Location Permission চায়, Allow নির্বাচন করুন।
  3. ফোনের Location/GPS চালু রাখুন।
  4. বাইরে বা জানালার কাছে থাকলে GPS Accuracy সাধারণত ভালো হতে পারে।
  5. চলন্ত অবস্থায় অবস্থান আপডেট দেখতে 🛰️ LIVE GPS ব্যবহার করুন।
  6. GPS বন্ধ করতে ⏹️ STOP GPS চাপুন।
⚠️ গুরুত্বপূর্ণ: GPS Location ব্যবহারের জন্য আপনার Browser-কে Location permission দিতে হবে। Internet/GPS signal, ফোনের Location setting এবং Browser permission-এর ওপর Accuracy নির্ভর করতে পারে।
